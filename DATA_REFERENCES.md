# Data references and licences

All data used by the demo come from third parties or from VITO's mapping pipeline. Please cite the sources below and
check each licence yourself before redistributing anything. See also [IMPORTANT_READ_FIRST.md](LIMITATIONS_AND_CAVEATS.md).
File paths below are relative to the [`NIP_top_down_demo`](NIP_top_down_demo) folder.

## 1. Habitat (ecosystem) maps - `Bent Farm` site (EUNIS levels 1-3, 2021 and 2024)

- **Bundled files:** `Demo_input_data\Demo_site\DemoHabitat_y2021_EUNISlvl3_buffered.tif` and
  `Demo_input_data\Demo_site\DemoHabitat_y2024_EUNISlvl3_buffered.tif`; the site boundary is
  `Demo_input_data\Demo_site\Demo_site_polygon.gpkg`.
- **Source:** generated by VITO with its ecosystem-mapping pipeline, using public input data. The method models the
  relationship between ecosystem type and environmental variables using vegetation plots from the European Vegetation
  Archive (EVA, https://euroveg.org/eva-database/), sPlotOpen (https://idiv-biodiversity.de/de/splot/splotopen.html) and
  GBIF, with remote-sensing data as predictors. The existing model for the Atlantic biogeographic region was run for
  the demonstration area for 2021 and 2024, giving the most likely EUNIS class in each 10 m pixel.
- **Code and tools:** https://github.com/VITObelgium and https://github.com/ESA-WEED-project; the methods are being
  integrated into an open-source tool for the ESA-WEED project (https://esa-worldecosystems.org/en).
- **Status:** **experimental, predictive output that is still in development and validation.** Do not treat it as a
  record of what is physically on the ground (see the warning file).
- **Reference-site maps:** `Demo_input_data\Reference_site\RefHabitat_y2021_EUNISlvl2.tif` and
  `Demo_input_data\Reference_site\RefHabitat_y2024_EUNISlvl2.tif`, produced in the same way, at EUNIS level 2.

## 2. EUNIS - GET - IUCN Red List crosswalk (the look-up table, LUT)

- **Bundled files:** `Demo_input_data\Demo_lookup_tables\LUT_EUNIS_GET_demo.csv` (classification crosswalk) and
  `Demo_input_data\Demo_lookup_tables\LUT_EUNIS_RedList_demo.csv` (Red List threat status).
- **Original source:** classification (crosswalk) tables from the EEA
  (https://sdi.eea.europa.eu/catalogue/srv/api/records/bfe4c237-e378-4a83-ab21-b3807f96c2e2?language=all) and the
  ESA-WEED project tools page (https://esa-worldecosystems.org/en/resources/tools). Further background: European Red
  List of Habitats (https://www.eea.europa.eu/en/datahub/datahubitem-view/de2276d8-e295-4cd7-89c9-88812065db87) and
  FloraVeg (https://floraveg.eu/).
- **Important - the LUT supplied here is site-specific and is NOT for use elsewhere.** The original crosswalk has
  many-to-one and one-to-many relationships: in Europe, a EUNIS class can belong to several different Global Ecosystem
  Typology (GET) classes depending on where it occurs. For this demo the LUT was derived from the original by choosing,
  for each EUNIS class, the **single** GET class most plausible for this site's location, using the GET class
  distributions on the GET website and removing the unlikely options.
- **Anyone applying the method to another site must start from the original EEA / WEED crosswalk and make their own
  site-appropriate selection.** Do not reuse the demo LUT.

## 3. Total Primary Production (TPROD / TPP) - Copernicus

- **Source:** Copernicus Land Monitoring Service, High Resolution Vegetation Phenology and Productivity - Total
  Productivity (https://land.copernicus.eu/en/products/vegetation/high-resolution-total-productivity).
- **The tiles are not redistributed here (about 200 MB each).**
  [`Metrics_scripts\Download_TPROD.py`](NIP_top_down_demo/Metrics_scripts/Download_TPROD.py) downloads the raw, unmodified tiles from
  Copernicus (via WEkEO) to `Demo_input_data\TPROD` by default.
- **Licence:** Copernicus Land Monitoring Service data are free and open, including commercial use, provided the
  source is acknowledged. Suggested acknowledgement: *"Generated using E.U. Copernicus
  Land Monitoring Service information; (c) European Union."* Please confirm the exact wording and terms on the product
  page (or in the Copernicus data policy) when you publish.

  https://sac.jncc.gov.uk/site/UK0019859.
- **`Demo_input_data\Reference_site\Peake_district_dales32630.gpkg` is only a clip (one site) of the original UKNSN polygon layer.** It is not our data and

- **Licence:** JNCC datasets are normally released under the Open Government Licence (OGL), which permits copying and
  adapting with attribution. Please check the licence statement on the JNCC download page for the current version and
  attribution text.
